2026.12.1-12.8 昆明·大理·丽江·香格里拉 家庭自由行手机网页版攻略。

## 功能

- **📅 行程**:D0-D7 每日时间轴,🎫门票价、💰花费标在每条边上;点带 📖 的名字弹出景点/美食介绍弹层(介绍、门票、开放时间、贴士)+ Google/苹果地图导航

- **🍜 美食**:昆明/大理/丽江/香格里拉 18 种美食,点开看详情
- **✅ 清单**:行前证件/防寒衣物/药品高原装备/行前任务/特产备忘,打勾自动保存
- **🧰 工具**:海拔速查+高反应对、应急电话一键拨打、点餐说法一键复制
- **💴 预算**:门票明细表、人均预算总表
- 顶部倒计时,单文件离线可用(无 CDN 依赖)
